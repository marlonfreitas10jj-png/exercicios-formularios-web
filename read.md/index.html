# Exercícios de Formulários Web Repositório desenvolvido como parte do processo seletivo para vaga de Programador Júnior. ## Tecnologias - HTML5 - CSS3 - Flexbox - Validação de formulários HTML5 - Design responsivo ## Atividades ### 01 - Formulário de cadastro Formulário contendo nome, e-mail, senha e botão de envio. ### 02 - Validação Aplicação de validações utilizando recursos nativos do HTML5, como `required`, `type="email"`, `minlength` e `pattern`. ### 03 - Login responsivo Formulário de login desenvolvido utilizando Flexbox e Media Queries. ### 04 - Fieldset e Legend Organização de informações pessoais e de endereço utilizando `fieldset` e `legend`. ### 05 - Formulário de pesquisa Formulário de pesquisa com campos de avaliação, comentários e botão de envio estilizado. ## Objetivo Demonstrar conhecimentos básicos de desenvolvimento front-end, semântica HTML, validação de formulários, CSS e responsividade.
